Feature 80 - C Debug Metadata Milestone 3: Baseline Variable Locations
=======================================================================

Status
------

Implemented and validated:

- O0 parameters and locals survive V6CLANG alloca-to-global promotion.
- Promoted homes use final linked `DW_OP_addrx` plus `DW_OP_plus_uconst`.
- Dynamic stack homes use `DW_OP_fbreg` relative to a CFA-based frame base.
- Register parameters use the frozen byte/pair map.
- Pointer parameters use pair-register locations.
- Proven constants use `DW_AT_const_value`.
- Stack arguments retain frame-relative locations.
- Final ELFs pass `llvm-dwarfdump --verify`.
- No optimization is disabled or removed.

Producer Changes
----------------

`V6ClangStaticDebugValues` runs after all machine optimizations. It finds
`llvm.dbg.declare` records rewritten by `V6ClangAllocaPromote`, removes stale
`$noreg` machine records, and emits stable global memory locations.

Generic DwarfDebug now accepts relocatable global-address operands in local
DBG_VALUE records and emits `DW_OP_addr`/`DW_OP_addrx` with an optional
`DW_OP_plus_uconst` offset.

In debug modules, accesses that maintain promoted local homes are volatile.
O43 remains enabled but does not replace debug `__v6clang_a.*` SHLD/LHLD homes
with transient PUSH/POP values. Release builds retain the existing
optimization.

Static Emulator Evidence
------------------------

At the HLT in `static_probe`, `__v6clang_a.static_probe` is at `0x0146`:

    parameter   DW_OP_addrx base       -> [0x0146] = 0x1122
    local       base + 2               -> [0x0148] = 0x1245
    addressable base + 4               -> [0x014A] = 0x1246

See `static-dwarf.txt` and `static-stop.txt`.

Dynamic Emulator Evidence
-------------------------

At the HLT in `dynamic_probe`:

    PC=0x016B, SP=0xFFF2
    active CFI: CFA=SP+14 = 0x0000
    DW_AT_frame_base: CFA-14 = 0xFFF2

The variable locations evaluate to:

    parameter   fbreg +10 -> [0xFFFC] = 0x3344
    local       fbreg +8  -> [0xFFFA] = 0x3578
    addressable fbreg +6  -> [0xFFF8] = 0x3579

This also validates 16-bit CFA wrap at `0x0000`. See `dynamic-dwarf.txt` and
`dynamic-stop.txt`.

Other Tested Forms
------------------

Permanent lit tests additionally cover:

- i8 parameter in A (`DW_OP_reg0`);
- i16 parameter in HL (`DW_OP_reg9`);
- pointer parameter in DE (`DW_OP_reg8`);
- register-local location transitions;
- `DW_AT_const_value 42`;
- stack-passed parameters;
- object/final relocations and 16-bit final addresses.

Assembly and Performance
------------------------

`v6clang_old.asm` and `v6clang_new01.asm` are identical release assembly.
Debug builds intentionally retain observable homes for declared variables.
Full release benchmark and regression results are recorded in the Milestone 3
implementation plan.

Known Limits
------------

Milestone 3 establishes baseline O0 locations and simple register/constant
forms. Optimized lifetime transitions, O61 patched-code locations, complex
pieces, and cross-pass location gaps remain Milestone 4 work.
